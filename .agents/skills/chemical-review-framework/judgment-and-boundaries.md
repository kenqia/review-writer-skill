# 判断框架、解释链与证据边界

本页把案例和关系压缩为能指导后续工作的化学判断。判断必须能回到 evidence matrix 和 locators，也必须让读者知道何处是模型综合或假设。

## Explanation chain

对每个核心判断，尽量连接以下节点：

`变量/干预 → 情境与对照 → 可观察终点 → 来源观察 → 解释关系 → 适用边界 → 可检验预测`

“机制”是反应和分子过程主题中可能采用的一种解释关系，不是材料、分析、环境或计算主题的强制术语。解释关系可以是结构—性质、条件—性能、方法—偏差、暴露—效应、模型—预测误差或其它由 brief 定义的关系。

每条链都要注明：支持它的案例和 locator、仍然可能的反例或 alternative explanation（替代解释）、不能外推的对象/条件，以及下一项最能区分解释的实验、计算或数据。预测要具体到可观察终点，不要写成无法证伪的愿景。

## Judgment framework 的结构

`judgment-framework.md` 对每项重要判断至少回答：

1. 判断是什么，范围和语气是什么；
2. 哪些来源观察支持它，比较对象、条件、对照、终点和分母是什么；
3. 哪些案例削弱、限定或反驳它，以及哪些 applicability boundary（适用边界）限制外推；
4. 作者假说与 Framework 的模型综合分别是什么；
5. 适用边界、混杂因素、未知值和不可比较处是什么；
6. 什么实验、计算或新来源可以检验或改变它。

来源直接支持的陈述使用 `SOURCE_FACT` 或等价自然语言；跨来源判断使用 `MODEL_SYNTHESIS`；尚未验证的推断使用 `MODEL_HYPOTHESIS`。不需要对每个连接句贴标签，但不能把推断写成来源报告。

## Evidence-bounded value check

价值检查只问当前材料是否已经超出 annotated bibliography：是否至少形成一个有具体终点支撑的判断、一个可解释的研究类型学、一个可靠的适用边界或一个值得检验的矛盾。它同时检查反例/替代解释、scope、locator 和下一步问题。

不要用论文数、案例数、表格行数、字数、query 数或其它固定阈值替代这个判断。小型文献可能有一个决定性对照；大型文献也可能全部不可比较。

## 非比较模式与 Chemical GAP

没有共同终点时，明确切换到：

- evidence map：哪些研究回答哪些局部问题；
- research typology：按体系、方法、证据类型或终点分组；
- local explanation chain：只在字段足够的子集内建立解释；
- `NOT_COMPARABLE` boundary：说明不能排序或合并的原因；
- `Chemical GAP`：指出需要新来源、原始 PDF 核验、统一测量或新实验的缺口。

缺一个表格字段不等于发现了新的科学空白；把 extraction gap 与 literature gap 分开，并给出不同的下一步。

## 无法形成判断时

如果当前范围只能得到来源摘要、互不相容的终点或无法定位的解析文本，写明“尚未形成可辩护的判断框架”，列出最早能解除阻塞的 Research 动作。可以交付 partial-scope 框架，但必须公开未覆盖区域和语气边界，不能用格式完整掩盖证据不足。
