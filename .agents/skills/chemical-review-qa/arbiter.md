# QA Arbiter

等四个独立观察回来后，arbiter 只读取各自报告和同一版 allowlisted brief/Research/draft 摘要；缺失或 malformed 的角度必须先标成 Incomplete QA，再继续汇总。把它们整理成研究者能读的三份材料：`qa/review-report.md`、`qa/qa-plan.md` 和 `qa/revision-plan.md`。保留冲突 conflict（冲突）：同一 claim 上的分歧、缺失 locator、化学不可比和不同严重性都可见，不用多数意见抹平它们。

报告里必须保留 claim/paragraph、locator（适用时）、severity、rationale、confidence、earliest return stage 和 suggested action。结果是可追踪的 review-report、QA-plan 和 revision-plan；结论是“下一步怎么查/怎么改”的建议，not pass/fail，也不是科学接受。缺 reviewer 时报告 Incomplete QA，不能让剩余角色冒充完整覆盖。

完成本页的标准是：研究者能看到每个重要问题的依据、冲突和推荐动作，并知道哪些问题仍然未知。
