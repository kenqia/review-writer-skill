# Chemical Framework 与 Publication 的边界

Status: accepted

Chemical Review 在 Research 与 Synthesis 之间增加第五个核心入口 `Framework`，专门把可信来源文本组织成跨研究、领域适配且可检验的化学判断框架；原先的 evidence-bounded value check 归入该入口。期刊化清理与 DOCX 生成保持为用户主动调用的独立 Publication 投影，不回写核心 Markdown 正文，也不把流程元数据带入读者稿。这样恢复案例深度和实验可操作性，同时避免把旧版强 orchestrator、provider runtime 或状态机带回核心产品。
