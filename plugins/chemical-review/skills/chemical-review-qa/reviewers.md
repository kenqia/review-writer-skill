# QA Reviewers

如果研究者想要第二双眼睛，主会话可以请四个 fresh sub-agent 分别阅读同一版 brief、Research evidence、Synthesis handoff 和 `draft.md`。每个 reviewer 只收到完成自己角色所需的 allowlist，不共享其它 reviewer 的报告。

四个默认角度是：

1. **evidence-locator**：来源 identity、原始 PDF locator、引用和 `SOURCE_FACT` 是否相互支持；
2. **chemistry-comparability**：底物/体系、催化剂状态、配体、条件、终点、对照和机制证据是否真的可比；
3. **synthesis-rebuttal**：比较、解释、反驳、矛盾结果和可检验假设是否有说服力；
4. **overclaim-counterexample**：范围漂移、过度确定性、反例、UNKNOWN 和 Chemical GAP 是否被诚实保留。

每份报告只写观察、locator、严重性、理由和下一步建议；没有问题就写检查范围。reviewer 不改 `draft.md`，不读隐藏上下文，也不替研究者宣布科学有效。
