# Revision Routing

研究者可以逐条用普通语言处理 finding：`accept`（接受）、`reject`（拒绝并说明理由）或 `defer`（暂缓并写清何时复查）。主会话把原话保存在 `qa/feedback.md`，再解释它最适合回到哪个阶段：

- **Intent**：问题、范围、排除项或贡献承诺需要重想；
- **Research**：缺来源、全文、locator、证据等级或比较字段；
- **Synthesis**：结构、综合、反驳、假设或表达需要改；
- **Delivery**：只涉及格式、图表、期刊指南或交付包装。

旧报告和旧稿保留，新的修改写出它影响的 claim。QA 反馈不会自行改稿，也不会替研究者推进下一个阶段；研究者说“补看这篇 PDF”或“保留这个假设”就足够作为下一步。
