# Synthesis Handoff

写作完成后，用 `synthesis-handoff.md` 给研究者一个短摘要：当前 draft revision、覆盖的核心论点、主要比较、使用的 Framework 判断主轴/案例、强 claim 的 locator、high-risk claims、counterexamples、假设、反例和 Chemical GAP，以及下一步适合写作、补证据还是做 QA。明确 next action，以及这是 candidate、partial-scope 还是 evidence-bounded draft。若 Framework 被跳过，记录这一决定及其对完整性声明的影响。

如果研究者愿意让 QA 阅读，可以写 `accept_draft_for_qa` 或用普通语言确认；这是 separate、独立于 plan confirmation 的高影响 checkpoint。也可以 `return_to_synthesis`、`return_to_research`、`return_to_framework` 或 `pause`。研究范围不完整时，明确它只是 `unreviewed; evidence-bounded; partial-scope` 候选稿，不是完整综述或科学认证。

完成本页的标准是：研究者能从 handoff 判断稿件的证据边界和下一步，不需要读内部日志或猜测状态。
