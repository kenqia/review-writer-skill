# Chemical Review plugin

`chemical-review` is the release-facing Codex plugin for the Review Writer
project. It packages one skill and its local Python support modules; it does
not include the development repository's tests, fixtures, or auxiliary skills.

This is an experimental `0.1.0-beta.1` release. It can help a researcher build
and iteratively improve a critical narrative chemistry review, but it does not
establish scientific validity, reproduce experiments, predict journal
acceptance, or replace human scientific editing.

The bundled workflow is:

`Grill → Research → Prototype → PRD → Issues → Implement → Review`

The clean manuscript and the researcher-marked view are generated from one
content source. Human feedback can route a later cycle back to the earliest
affected phase.

For development, the canonical editable source remains
`../../.agents/skills/chemical-review/`. The files under `skills/chemical-review/`
are generated by `scripts/build_plugin.py`; do not edit the generated copy by
hand. See the repository README for the development, validation, and release
workflow.
